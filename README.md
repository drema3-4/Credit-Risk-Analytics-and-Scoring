# Credit Risk Analytics & Scoring
---
## Цель проекта
Проанализировать характеристики кредитного риска заёмщиков и создать интерпретируемую систему ранжирования рисков для сегментации клиентов и анализа кредитной политики.
---
## Основные бизнес вопросы
1. Какие характеристики связаны с повышенным кредитным риском?
2. Какие сегменты формируют наибольшую долю bad-займщиков?
3. Можно ли ранжировать клиентов по уровню риска?
4. Как меняется portfolio bad rate при различных cutoff?
---
## Словарь данных

| Признак               | Описание                                                                                                                                                         | Тип     | Роль    |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------- | ------- |
| target                | Наличие у клиента просрочки 90 и более дней или более серьёзное нарушение платёжной дисциплины в следующие 2 года.                                               | binary  | target  |
| revolving_utilization | Общий баланс по кредитным картам и личным кредитным линиям, кроме недвижимости и долгов в рассрочку, например автокредитов, делённый на сумму кредитных лимитов. | percent | feature |
| age                   | Возраст заёмщика в годах.                                                                                                                                        | integer | feature |
| num_30_59_days_late   | Количество раз, когда заёмщик имел просрочку 30-59 дней, но не хуже, за последние 2 года.                                                                        | count   | feature |
| debt_ratio            | Ежемесячные выплаты по долгам, алименты и расходы на проживание, делённые на ежемесячный валовый доход.                                                          | percent | feature |
| monthly_income        | Ежемесячный доход.                                                                                                                                               | float   | feature |
| num_open_credit_lines | Количество открытых кредитов, например, автокредит или ипотека, и кредитных линий, например кредитных карт.                                                      | count   | feature |
| num_90_days_late      | Количество раз, когда заёмщик имел просрочку 90 дней или более.                                                                                                  | count   | feature |
| num_real_estate_loans | Количество ипотечных и других кредитов, связанных с недвижимостью, включая кредитные линии под залог жилья.                                                      | count   | feature |
| num_60_89_days_late   | Количество раз, когда заёмщик имел просрочку 60–89 дней, но не хуже, за последние 2 года.                                                                        | count   | feature |
| num_dependents        | Количество иждивенцев в семье, не включая самого заёмщика: супруг/супруга, дети и т. д.                                                                          | count   | feature |
